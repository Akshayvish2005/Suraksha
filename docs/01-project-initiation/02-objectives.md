# 2. Project Objectives

## 2.1 Overall goal

Deliver a working, pilot-tested digital platform that improves disaster preparedness
knowledge and response readiness among students and staff of schools and colleges.

## 2.2 SMART objectives

> Targets below are **proposed** and should be confirmed with your guide/team before
> they are frozen in the requirements phase.

| ID | Category | Objective | Measure of success |
|---|---|---|---|
| **O1** | Education | Build structured, curriculum-style learning modules for **earthquake, flood and fire**, each with lessons, examples and a quiz | 3 hazard modules completed, each in English and Hindi |
| **O2** | Simulation | Build interactive scenario simulations where the learner makes decisions and sees consequences | At least 1 branching scenario per hazard (3 total) with scoring and feedback |
| **O3** | Virtual drills | Let institutions schedule and run virtual drills for a class, department or whole campus | Admin can create a drill; participants complete it; a drill report is generated |
| **O4** | Assessment | Measure learning before and after training | Pre-test and post-test on every module; **≥ 25% average score improvement** in the pilot |
| **O5** | Readiness tracking | Give administrators a dashboard of participation, scores and readiness | Dashboard shows participation %, average scores, drill history and a readiness indicator; reports exportable (PDF/CSV) |
| **O6** | Safety planning | Provide digital tools to prepare an institution-specific emergency plan | Editable emergency plan template, evacuation route/assembly point info, emergency contact directory |
| **O7** | Accessibility | Make the system usable on low-end devices and low bandwidth | Runs on a basic smartphone browser; core content loads in a reasonable time on a slow connection |
| **O8** | Validation | Test the system with real users | Pilot with **1–2 institutions and at least 100 users**; average satisfaction **≥ 4 / 5** |

## 2.3 Objectives mapped to deliverables

| Objective | Main deliverable |
|---|---|
| O1 | Learning module content + module viewer |
| O2 | Scenario simulation engine + 3 scenarios |
| O3 | Drill scheduler, drill player, drill report |
| O4 | Quiz/assessment engine with pre/post comparison |
| O5 | Admin dashboard and reports |
| O6 | Emergency plan builder and contact directory |
| O7 | Responsive, lightweight web front end |
| O8 | Pilot plan, test report and feedback analysis |

## 2.4 Priority of objectives (MoSCoW)

| Priority | Objectives |
|---|---|
| **Must have** | O1, O2, O3, O4, O5 |
| **Should have** | O6, O7, O8 |
| **Could have** | Additional hazards, gamification (badges, leaderboards), multilingual beyond Hindi/English |

## 2.5 Key performance indicators (KPIs)

| KPI | How it is measured |
|---|---|
| Knowledge gain | Average post-test score minus pre-test score |
| Participation rate | Users who complete a module ÷ users enrolled |
| Drill completion rate | Participants who finish a drill ÷ participants assigned |
| Response quality | Percentage of correct decisions in scenarios |
| User satisfaction | Survey score (1–5) |
| System reliability | Successful sessions ÷ total sessions during the pilot |
